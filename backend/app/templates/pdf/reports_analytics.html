Report definitions and coverage

Scope: {{ scope_label }}. Aggregates and details use the same authorized project cohort. Fiscal year selects projects by funding year; activity includes the recorded history of those projects, not only events occurring within that calendar year.

Document compliance = compliant active requirements / applicable active requirements (waived requirements are tracked separately and do not count as compliant evidence). Open = pending + under review + non-compliant. Requirements marked not applicable are excluded from open obligations and the compliance rate denominator.

Schedule variance = actual minus target in percentage points, derived from the latest MPR with both values. Negative means behind; positive means ahead. An incomplete MPR is unreported. Allocation represents the recorded project budget amount in project master records.

Closeout matrix readiness tracks internal completion matrix deliverables (Final SWA, Final Inspection Report / IAR, Certificate of Final Acceptance, Final SORD, and Proof of Fund Return where applicable) for 100% physically completed projects.

Coverage: project implementation status, active documentary compliance, return summaries, and completion matrix deliverables.{% if include_appendix %} The supporting appendix includes full workflow routing history and individual records.{% endif %} This report does not replace financial reconciliation, MAR/Form 3/exception case registers, account/security audits, workbook contents, correspondence, or independently released checker benchmark reports.
