# Annex C: Program Monitoring Checklist

This reference guide provides the complete, authoritative structure, evaluation criteria, and operational review procedure of **DILG Annex C (dated August 10, 2022)**, cross-referenced with the **PDMU Operations Manual Final (2024)** and {app_name}'s technical review consoles.

---

## 1. Statutory Identification & Purpose

* **Official Document Title:** Annex C — Program Monitoring Checklist (dated August 10, 2022).
* **Authority Level:** Level 1 (Official Authoritative Policy).
* **Governing Mandate:** DILG Local Government Support Fund Omnibus Guidelines (MC No. 2023-063) and PDMU Operations Manual Final (2024, pp. 16–17, 31–32).
* **Core Purpose:** Serves as the primary standardized technical inspection and desk evaluation instrument used by DILG C/MLGOOs, Cluster Heads, and Provincial PDMU civil engineers to evaluate documentary completeness, statutory compliance, and field milestones across the full project lifecycle.
* **Relationship to Annex B:** Annex B defines *what* documents the LGU must submit; Annex C defines *how* DILG personnel inspect, verify, and grade those submissions.

---

## 2. Header Information & Metadata

Every accomplished Annex C checklist must record complete administrative and project identifiers:
* **Administrative Routing:** `REGION`, `PROVINCE`, `NAME OF LGU`.
* **Program Classification:** Program / Project type (referencing Appendix A of Omnibus Guidelines).
* **Project Profile:**
  * `PROJECT TITLE`: Official project title conforming to the Sanggunian resolution and GAA appropriation.
  * `PROJECT LOCATION`: Barangay, Municipality/City, and specific site coordinates.
  * `AMOUNT REQUESTED / ALLOCATED`: Numerical grant amount in Philippine Pesos ($\text{PHP}$).
  * `TARGET BENEFICIARY`: Direct beneficiary communities, demographic count, or sector.

---

## 3. The Nine Component Tables of Annex C

Inspection of the primary source document (`Annex-C-Program-Monitoring-Checklist-8.10.22.docx`) establishes nine distinct component tables governing specific project types, programs, and evaluation stages:

### Table 0: Program / Project Profile Matrix
* Identifies project categorization by program year (e.g., FY 2021 LGSF-FALGU, DRRAP, AC, etc.) and physical modality:
  * Infrastructure Projects (roads, bridges, water systems, evacuation centers).
  * Motor Vehicles (ambulances, disaster trucks, patrol vehicles).
  * Non-Infrastructure (medical devices, financial aid, livelihood assistance).

### Table 1: Pre-Release / Fund Release Checklist (FALGU)
* **Documentary Verification:**
  * Letter Request or Special Budget Request (SBR) duly signed by the Local Chief Executive (Governor, Mayor, or Punong Barangay), stating project title, location, and requested amount.
  * Duly Notarized Omnibus Sworn Statement (OSS) certifying project eligibility and absence of duplicate funding.

### Table 2: CMGP & Assistance to Cities (AC) Checklist
* **Conditional Matching Grant to Provinces (CMGP) & Assistance to Cities (AC):**
  * Sangguniang Resolution endorsing the project(s) included in the latest Local Road Network Development Plan (LRNDP), duly approved Local Development Investment Program (LDIP), and Annual Investment Program (AIP).
  * Project Brief signed by the LCE.
  * Duly Notarized Omnibus Sworn Statement.

### Table 3: General Documentary Requirements for Other Programs
* Sangguniang Resolution endorsing the specific programs/projects.
* Sangguniang Resolution authorizing project execution and LCE contract signing.

---

### Table 4: Comprehensive Lifecycle Monitoring Checklist (43 Items Across 9 Columns)

Table 4 is the core technical evaluation instrument used during ongoing monitoring. It organizes 43 discrete checkpoints across a **9-column evaluation matrix**:

```
┌────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│                                       Table 4 Column Structure                                        │
├───────────────┬──────────────┬──────────────┬─────────┬──────────────────────┬─────────────┬───────────┤
│ DOCUMENTARY   │ APPLICABLE   │ LOCAL BUDGET │  ANNEX  │     AVAILABILITY     │ ACTUAL DATE │  REMARKS  │
│ REQUIREMENTS  │ TO PROJECT   │ CIRCULAR NO. │         ├──────────┬───────────┤             │           │
│               │              │              │         │   YES    │    NO     │             │           │
└───────────────┴──────────────┴──────────────┴─────────┴──────────┴───────────┴─────────────┴───────────┘
```

The checklist progresses through three mandatory lifecycle stages:

#### Part A: Pre-Procurement Stage
1. **Notice of Authority to Debit Account Issued (NADAI):** Mandatory recording of official NADAI number in the Remarks column.
2. **SubayBAYAN Enrollment:** Verification of project enrollment in the SubayBAYAN Portal within 15 working days upon receipt of NADAI.
3. **Confirmation on Receipt of Fund:** Official LGU confirmation of credited allocation.
4. **Proof of Transfer of Fund to LGU Trust Fund:** Bank statement or deposit certification of dedicated trust account.
5. **Authority to Purchase Motorized Vehicle (APMV):** DBM/DILG confirmation letter (for vehicle acquisitions).

#### Part B: Procurement Stage (By Contract)
1. **ITB Posting in PhilGEPS:** Printout with PhilGEPS reference number and conspicuous public posting.
2. **Opening of Bids:** Minutes of bid opening and preliminary bid evaluation sheets.
3. **Issuance of Notice of Award (NOA):** Copy of NOA with winning bidder's signed Conforme.
4. **Issuance of Notice to Proceed (NTP):** Copy of NTP with contractor's signed Conforme specifying contract start date.
5. **Contract Agreement:** Executed and notarized contract agreement, contractor's PCAB license, and performance bond.

#### Part C: Project Implementation Stage
1. **Project Signboard:** Verified on-site billboard installation per COA Circular No. 2013-004.
2. **Request for Work Inspection:** Contractor formal inspection transmittals.
3. **Concrete Pouring Permit:** Mandatory engineering permit prior to structural concrete pours.
4. **Site Instruction:** Supervising engineer's on-site directive sheets.
5. **Water Source Validation Certification:** Potability and discharge certification signed by Municipal Engineer (for water supply).
6. **Notice of Defects and Deficiencies (Annex E):** Filed copies of issued deficiency notices.
7. **Certificate of Completion:** Signed completion certificate.
8. **Certificate of Acceptance:** For vehicle acquisition projects.
9. **Report on Fund Utilization & Status (Annex I):** Current quarterly utilization report.
10. **Non-Infrastructure Monitoring Templates (MT1–MT4A):** Complete distribution summaries, receipts, and beneficiary sheets.

---

### Table 5: For SBDP Projects Only (Implementation Stage)
Technical compliance evaluated directly in coordination with the DILG Provincial Engineer:
* Program of Works (POW) adherence to standard engineering norms.
* Detailed Engineering Design (DED) blueprints, structural calculations, and technical specifications.
* Detailed Estimates and Unit Price Analysis.
* Geotechnical Soil Investigation reports (for vertical structures and bridges).
* Hydraulic and Drainage Analysis.
* Complete Right-of-Way (ROW) documentation.
* Environmental Compliance (ECC or CNC).

### Table 6: After Defects Liability Period (DLP)
* **Certificate of Final Acceptance:** Formal certification executed after the mandatory 1-year Defect Liability Period and post-DLP joint validation.

### Table 7: Motor Vehicles Verification
* Profile of Newly Delivered Vehicles (engine/chassis numbers, model, color).
* Delivery Receipts and Sales Invoices.
* LGU Certificate of Inspection and Acceptance.

### Table 8: Posting & Reportorial Requirements
* Full compliance with public posting under RA 9184 and its 2016 Revised IRR.
* Timely quarterly submission of fund utilization and project progress reports.
* Routine SubayBAYAN monthly data encoding (due on the 25th of each month) with geotagged photo uploads.

## 4. Procedural Workflow & Prescribed Review Cadence

The PDMU Operations Manual Final (2024, pp. 16–17, 31–32) establishes the official review sequence and strict processing turnarounds for Annex C:

```
┌─────────────────────────────────────────────────────────────────────────────────────────────────┐
│                                 Annex C Review Cadence & Routing                                │
├─────────────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                                 │
│  [ LGU ] ─── Submits Pre-Implementation Documents                                              │
│     │                                                                                           │
│     ▼ (Within 15 working days upon NADAI)                                                       │
│  [ C/MLGOO ] ─── Evaluates completeness, accomplishes Annex C, and endorses                    │
│     │                                                                                           │
│     ▼ (Within 3 working days)                                                                   │
│  [ Cluster Head ] ─── Reviews & transposes endorsement to Provincial Office                     │
│     │                                                                                           │
│     ▼ (Within 5 working days upon receipt of Annex C)                                           │
│  [ PDMU PO Engineer ] ─── Evaluates Annex C against LBCs, verifies DED/POW, logs findings       │
│     │                                                                                           │
│     ▼ (Within 5 working days upon receipt of Annex C report)                                    │
│  [ Regional Office ] ─── Formulates official resolution / concurrence on observations           │
│                                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘
```

* **C/MLGOO Field Review Window:** Accomplishes Annex C within **15 working days** upon LGU receipt of NADAI (Manual p. 16 Step 2 Seq. 3).
* **PDMU Provincial Engineer Review Window:** Evaluates compliance through Annex C within **5 working days upon receipt of Annex C** (Manual p. 17 Step 2 Seq. 4).
* **Regional Resolution Window:** DILG Regional Office provides formal resolution to observations within **5 working days upon receipt** (Manual p. 17 Step 2 Seq. 5).
* **Provincial Quality Filtering Mandate:** PDMU PO engineers verify that unit costs align with DPWH Construction Materials Price Data (CMPD) and that design parameters comply with national codes. If defects are identified, the evaluator issues a **Notice of Deficiencies (Annex E)**.

## 5. System Implementation in {app_name}

* **Project Requirements Review Console (`/dashboard/projects/:id` - Requirements Tab):**
  * Evaluators cross-examine submitted PDF plans and bid attachments against the Annex C criteria.
  * During active evaluation, `workflow_status` transitions to `"under_verification"`, while `compliance_status` remains `"under_review"`.
* **Field Monitoring Console (`/dashboard/monitoring`):**
  * Field officers log physical inspection observations, photo documentation, and milestone verifications aligned with Annex C sections.
* **Return Integration:** When an evaluation reveals omissions, non-conforming rates, or missing certifications, the reviewer executes **Return for Revision**, mapping findings to the canonical deficiency categories derived from Annex C.
